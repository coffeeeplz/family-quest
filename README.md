# 가족 퀘스트

가족이 그룹을 만들어 함께 쓰는 퀘스트(할 일)와 코인 앱입니다.
부모가 퀘스트를 등록하고, 자녀가 완료를 알리면, 부모 중 한 명이 확인한 뒤 코인이 적립됩니다.

### 정해 둔 규칙

- 놓친 일: 반복 퀘스트는 최근 3일 치까지 보이고 늦게 하면 절반. 기한 지난 한 번짜리는 끝낼 때까지 남고 코인은 그대로.
- 코인 협상: 자녀가 직접 추가한 한 번짜리 일만. 주고받는 횟수(기본 3번)와 제안 상한(기본 50코인)은 가족 설정에서 바꿈.
  횟수를 다 쓰면 마지막 제안을 받은 쪽이 수락하거나 거절. 거절되면 코인 없는 메모로 남음.
- 자주 쓰는 퀘스트 버튼: 누르면 오늘 할 한 번짜리 퀘스트가 됨. 자녀가 누를 수 있는 버튼은 하루 한 번.
- 상점: 자녀가 신청하면 그만큼의 코인이 묶이고, 부모가 승인할 때 코인이 빠짐. 거절하거나 취소하면 묶인 코인이 풀림.
  승인된 보상은 "받을 보상"에 남아 있다가 부모가 "줬어요"를 누르면 마무리. 잔액은 0 아래로 내려가지 않음.
  구매 제한의 일주일은 월요일부터 일요일까지. 거절된 신청은 횟수에 세지 않음.
- 보상 제안: 자녀가 상점의 `+ 보상 제안`으로 이름, 그림, 원하는 가격을 적어 보내면 부모의 승인 화면 "보상 제안"에 나옴.
  부모는 그 가격으로 올리기, 다른 가격 제안, 거절(한마디) 중 하나를 고름. 주고받는 횟수는 코인 협상 설정(기본 3번)을 같이 씀.
  횟수를 다 쓰면 마지막에 받은 쪽이 수락하거나 그만둠. 합의되면 그 가격의 보상이 상점에 올라가고(구매 제한 없음, 상점 관리에서 고칠 수 있음)
  코인은 빠지지 않음. 사는 것은 따로 신청하고 승인받음. 자녀가 동시에 걸어 둘 수 있는 제안은 3개까지.
  자녀가 답할 차례인 제안은 상점 화면의 "가격 협상"과 상점 탭의 숫자로, 기다리는 제안과 오늘 거절된 제안은 "내 신청" 안에 보임.
- 코인 축하 연출: 코인이 들어오면 화면에 코인이 쏟아지고(금액만큼, 8~28개) 위쪽 잔액이 차례로 올라감. 연속 달성 보너스는 더 크게 축하하고,
  받은 코인으로 목표 저금통을 처음 채우면 "목표 달성!" 장면이 이어짐. 앱을 꺼 둔 사이 받은 코인은 다음에 열 때 "그동안 받은 코인"으로 한 번에 보여 줌
  (마지막으로 본 시각을 기기에 저장). 화면이 꺼져 있는 동안 생긴 장면은 다시 켰을 때 보여 줌.
  효과음(브라우저가 직접 만드는 도트 게임풍 소리)과 진동은 자녀의 더보기에서 켜고 끔. 진동은 안드로이드만 되고, 소리는 화면을 한 번 만진 뒤부터 남.
  기기에서 "동작 줄이기"를 켜 두면 쏟아지는 효과와 숫자 움직임은 나오지 않음.
- 목표 저금통: 자녀가 보상 하나를 목표로 정하면 상점에 남은 코인이 보임(부모는 자녀 현황의 접어 둔 구역에서 봄).
- 아래 탭: 부모도 자녀도 홈 / 퀘스트 / 캘린더 / 뭐먹지 / 더보기. 앱을 열면 홈이 먼저 보임.
  부모의 홈은 가족 메모, 오늘·내일 일정, 그 아래 승인 카드(옆으로 밀면 자녀 현황). 부모의 상점 관리는 더보기와 홈의 "더 보기" 안에 있음.
  자녀의 홈은 오늘 퀘스트 진행(누르면 퀘스트 화면), 코인 아래 작은 `여기예요` 버튼, 가족 메모, 오늘·내일 일정, 놓친 일.
  자녀의 퀘스트 화면은 놓친 일, 오늘 할 일(`+ 추가`), 코인 협상, 다가오는 일(접힘). 상점은 코인 아래 `상점` 버튼으로 들어감.
  탭의 숫자: 홈은 확인 안 한 메모(부모는 답할 일 포함), 자녀의 퀘스트는 남은 퀘스트와 답할 협상의 수.
- 가족 메모: 부모도 자녀도 남김. 100자까지, 받을 사람(가족 모두 또는 고른 사람)과 사라질 날짜(기본은 지울 때까지)를 정함.
  받은 사람에게는 확인하기 전까지 큰 카드로 보이고, `확인했어요`를 누르면 한 줄로 줄어듦. 쓴 사람에게는 "딸 확인 · 엄마 아직"처럼 보임.
  메모는 쓴 사람과 받은 사람에게만 보임. 고치기와 지우기는 쓴 사람과 부모만. 고치면 다시 확인받음(고친 사람의 확인만 남음).
  한 줄 메모는 5개까지 보이고 나머지는 "지난 메모"에 접힘. 가족이 남겨 둘 수 있는 메모는 30개까지. 답글은 없음(대화는 나중의 가족 채팅에서).
- 화면 정리: 부모 홈의 승인 구역은 답할 카드만. 새 퀘스트는 머리말의 작은 + 버튼, 칭찬 코인·상점 관리·가족 설정은 "더 보기" 안.
  자녀 현황의 위치는 한 줄이고 누르면 지도 링크·지난 위치·이름 붙이기가 나옴. 다가오는 일·목표 저금통·최근 코인 기록은 접어 둠.
  자녀 상점의 신청한 보상·받을 보상은 "내 신청" 한 줄로 모으고 누르면 자세히 나옴.
  가족 설정은 항목과 지금 값만 보이는 목록이고, 항목을 누르면 안쪽 화면에서 고치고 저장함.
- 캘린더: 누구나 일정을 올림. 고치기와 지우기는 올린 사람과 부모만(자녀도 자기가 올린 일정은 고치고 지움).
  일정은 하루 종일 또는 시각, 여러 날(31일까지), 반복(매주/매달/매년, 끝나는 날 선택)을 정할 수 있음.
  "누구 일정"을 고르지 않으면 가족 모두의 일정. 달력의 점은 그 사람의 캐릭터 색, 노란 점은 한 번짜리 퀘스트의 기한.
  누구 일정만 볼지와 퀘스트 기한 표시는 "더 보기" 안에 있음. 달력을 좌우로 밀면 달이 넘어감.
  공휴일은 빨간색. 해마다 같은 날은 계산하고, 설·추석·부처님오신날·대체공휴일·선거일은 `domain/holidays.ts` 의 표에
  2027년까지 넣어 둠(그 뒤는 해마다 표에 추가). 일정 알림은 푸시 대신 홈의 오늘·내일 일정 줄로 보여 줌.
- 뭐먹지: 첫 화면에는 지금 먹고 싶은 메뉴만 보임. 분류로 거르기, 메뉴 보관함, 분류 관리는 "더 보기" 버튼 안에,
  링크·메모·별점·먹은 기록·고치기는 카드를 누르면 나오는 창 안에 있음.
  분류는 가족 설정에 저장되고 부모가 분류 관리 화면에서 고침. 기본은 한식 / 중식 / 일식 / 빵 / 기타.
  "기타"는 지울 수 없고, 지운 분류나 예전 분류(집밥 등)의 메뉴는 기타로 보임(메뉴에 적힌 값은 그대로 둠).
  별점은 가족 각자가 메뉴마다 하나씩(1~5) 주고 언제든 바꿈. 화면에는 각자의 최신 점수를 평균 낸 값이 보임.
  "먹었어요"를 누르면 그날이 기록되고(하루 한 번) 보관함으로 가며, 바로 별점을 물어봄(건너뛸 수 있음).
  보관함에서 "또 먹고 싶어"를 누르면 다시 올라감. 같은 이름을 다시 적으면 새로 만들지 않고 있던 메뉴를 올림.
  고치기와 지우기는 올린 사람과 부모만. 링크는 웹 주소(http, https)만 받고 새 창으로 열림.
- 알림(푸시): 각자 더보기 > 알림에서 이 기기의 알림을 켜고, 받을 종류와 시각을 정함(기기마다 한 번씩 켬).
  부모: 완료 요청, 코인 제안, 보상 신청과 제안, 가족 메모, 아침 일정. 자녀: 새 퀘스트, 승인과 코인(칭찬 코인 포함), 협상 내 차례,
  보상, 가족 메모, 저녁 할 일(아직 안 한 "꼭" 할 일), 아침 일정.
  조용한 시간(기본 밤 10시~아침 7시)에는 보내지 않음. 저녁 할 일(기본 8시)과 아침 일정(기본 7시 반)은 정한 시각에 옴.
  아이폰은 iOS 16.4 이상에서 홈 화면에 추가한 앱으로 열었을 때만 켤 수 있음(앱이 안내함). 브라우저 규칙상 받은 알림은 반드시 보여 주므로
  앱을 보고 있는 동안에도 알림이 올 수 있음.
  알림 서버는 `functions/`(Firebase Cloud Functions, 서울). 무엇을 누구에게 보낼지는 `src/domain/pushMessages.ts`,
  시각 규칙은 `src/domain/push.ts` 에 있고 앱과 같은 규칙을 그대로 묶어 올림. 15분마다 저녁·아침 알림을 보낼 사람을 살핌.
- 위치: 자녀가 "지금 여기예요"를 누르면 그 순간의 위치가 가족에게 전해지고, 가족 설정에 정한 코인(기본 1)을
  하루 정한 횟수(기본 3번)까지 바로 받음. 횟수를 넘겨도 위치는 전해지고 코인만 없음.
  위치 권한을 허용해 둔 기기에서는 앱을 열 때(15분 간격)와 퀘스트를 끝낼 때도 위치가 자동으로 남음(코인 없음).
  앱이 꺼져 있을 때의 기록은 웹앱으로는 불가능. 실시간 위치는 구글 패밀리 링크 바로가기로 봄.
  위치 기록은 최근 7일 치만 보이고, 부모가 앱을 열 때 오래된 기록을 지움.
  부모가 장소(집, 학교, 학원 등)에 이름을 붙여 두면 그 반경 안의 위치가 "학원 근처"처럼 보임.
- 위치 공유 코인만은 부모의 승인 없이 본인이 받는다. `firestore.rules` 가 금액(설정값), 하루 횟수, 날짜를 검사해서
  그 이상은 받을 수 없게 막는다. 기본값(1코인, 3번)은 `domain/settings.ts` 와 규칙 두 곳에 같은 값으로 적혀 있다.
- 자녀 현황: 부모만 봄. 자녀의 홈과 같은 계산을 쓰므로 자녀가 보는 것과 항상 같음. 읽기 전용이고,
  칭찬 코인 주기와 퀘스트 추가만 여기서 바로 할 수 있음.
- 좌우로 밀기: 왼쪽으로 밀면 다음 쪽. 화면 가장자리 24px 안에서 시작한 동작은 휴대폰의 뒤로 가기와 겹치므로 무시.
  PC 에서는 위쪽 버튼으로 넘김.
- 연속 달성: 그날의 반복 퀘스트를 모두 제때 끝낸 날이 이어진 횟수. 반복 퀘스트가 없는 날은 건너뜀.
  늦게 한 퀘스트와 한 번짜리 퀘스트는 세지 않음. 기본은 3일마다 보너스 10코인.

## Firebase 연결 순서 (한 번만 하면 됨)

1. https://console.firebase.google.com 에서 프로젝트를 만든다. (Google 애널리틱스는 꺼도 됨)
2. **Authentication > 로그인 방법**에서 "Google"과 "이메일/비밀번호"를 켠다.
3. **Firestore Database**를 만든다. 위치는 `asia-northeast3 (서울)`, 모드는 "프로덕션 모드".
4. Firestore의 **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 통째로 붙여 넣고 게시한다.
5. **프로젝트 설정 > 내 앱**에서 웹 앱(`</>`)을 추가하고, 나오는 설정값을 `src/config/firebase.ts` 에 옮겨 적는다.
6. 앱을 올릴 주소가 정해지면 **Authentication > 설정 > 승인된 도메인**에 그 주소를 추가한다.

## 배포 (GitHub Pages)

- 코드는 이 프로젝트 전용 GitHub 저장소에 올린다. `main` 가지에 올라오면 `.github/workflows/deploy.yml` 이
  자동으로 검사(`npm test`)와 빌드를 하고 `https://<계정>.github.io/<저장소>/` 주소에 배포한다.
- 저장소 Settings > Pages 의 Source 는 "GitHub Actions" 로 둔다.
- 배포 주소의 도메인(`<계정>.github.io`)을 Firebase 의 승인된 도메인에 추가해야 Google 로그인이 된다.
- `src/config/firebase.ts` 의 값은 공개돼도 되는 식별자다. 데이터 보호는 `firestore.rules` 가 맡는다.
- 같은 배포 과정에서 `firestore.rules` 도 Firebase 에 자동으로 게시된다("규칙 게시" 단계).
  저장소 Settings > Secrets and variables > Actions 의 `FIREBASE_SERVICE_ACCOUNT` 에 배포 전용 서비스 계정
  (역할: Firebase Rules Admin, Service Usage Consumer)의 JSON 키가 들어 있어야 한다. 없으면 이 단계만 건너뛴다.
  이 키는 Secrets 에만 두고 저장소 파일이나 PC 폴더에는 절대 넣지 않는다. 규칙에 문법 오류가 있으면 이 단계가 실패한다.
- 알림 서버도 같은 키로 "알림 서버 배포" 단계에서 올라간다. Firebase 가 Blaze(종량제)여야 하고, 배포 계정에
  편집자(Editor)와 프로젝트 IAM 관리자(Project IAM Admin) 역할이 있어야 한다(첫 배포 때 서비스 에이전트에 역할을 주기 때문).
  실패하면 오류가 실행 기록의 주석으로 남고, "권한 살피기" 단계가 배포 계정의 역할을 주석으로 남긴다.

## 폴더 구조

```
src/
  config/firebase.ts   Firebase 설정값 (비어 있으면 체험 모드)
  backend/             저장소. types.ts 가 약속, firebase.ts 와 demo.ts 가 구현
  domain/              규칙과 계산 (세 구역 나누기, 절반 지급, 협상 차례, 연속 달성, 설정, 초대코드)
  app/                 로그인 상태, 가족 데이터 구독, 화면 틀과 탭
  features/            화면. 기능마다 폴더 하나
    auth/ onboarding/ avatar/ quests/ approvals/ negotiation/ home/ notes/ notify/ shop/ wishes/ celebrate/ food/ location/ calendar/ ledger/ family/ settings/ more/
  ui/                  도트 그림, 버튼, 창, 알림, 좌우로 넘기는 화면 묶음 같은 공용 부품
  styles/tokens.css    색, 글꼴, 치수 (분위기를 바꾸려면 여기만)
  assets/sprites.json  아바타와 아이콘의 도트 그림 데이터
firestore.rules        서버 보안 규칙 (누가 무엇을 할 수 있는지)
functions/             알림 서버 (Firebase Cloud Functions). src/index.ts 가 앱의 src/domain 규칙을 불러 쓴다
public/push-sw.js      서비스 워커에서 알림을 보여 주고, 누르면 앱을 여는 코드
tests/                 규칙과 저장소 동작 자동 검사
tools/                 아이콘 생성, 화면 흐름 검사 스크립트
```

새 기능을 붙일 때는 `backend/types.ts` 에 데이터와 메서드를 추가하고,
`features/` 에 폴더를 만들고, `app/Shell.tsx` 에 화면을 한 줄 더하면 됩니다.
아래 탭은 다섯 개까지만 두고, 그보다 늘어나는 화면은 더보기(`features/more/MorePage.tsx`)에 한 줄씩 추가합니다.
화면에는 핵심 목록 하나와 주요 버튼 두세 개만 두고, 나머지는 버튼을 눌러 나오는 창이나 안쪽 화면에 넣습니다.

## 데이터 구조 (Firestore)

| 위치 | 내용 |
|---|---|
| `users/{uid}` | 내가 속한 가족 |
| `invites/{code}` | 초대코드 (가족, 역할, 만료 시각) |
| `families/{fid}` | 가족 이름, 설정(협상 횟수, 제안 상한, 연속 달성, 칭찬 한마디, 위치 공유 코인, 뭐먹지 분류) |
| `families/{fid}/members/{uid}` | 역할, 이름, 캐릭터, 코인 잔액, 연속 달성 기록, 목표 보상, 오늘 위치 공유 코인을 받은 횟수 |
| `families/{fid}/quests/{id}` | 퀘스트 (받는 사람, 코인, 반복, "꼭" 표시) |
| `families/{fid}/runs/{퀘스트id_날짜}` | 수행 기록 (제출 → 승인/반려, 늦음 여부, 한마디) |
| `families/{fid}/ledger/{id}` | 코인 장부 (추가만 가능: 퀘스트, 보너스, 칭찬 코인, 위치 공유, 보상 사용은 음수) |
| `families/{fid}/presets/{id}` | 자주 쓰는 퀘스트 버튼 |
| `families/{fid}/proposals/{id}` | 자녀가 직접 추가한 할 일과 코인 협상 |
| `families/{fid}/rewards/{id}` | 상점의 보상 (이름, 가격, 그림, 구매 제한) |
| `families/{fid}/orders/{id}` | 보상 신청 (신청 → 승인/거절 → 받음) |
| `families/{fid}/foods/{id}` | 뭐먹지의 메뉴 (이름, 분류 id, 링크, 먹고 싶어 하는 사람, 먹은 날, 가족별 별점) |
| `families/{fid}/locations/{id}` | 위치 기록 (누구, 좌표, 오차, 시각, 직접 알림/자동, 받은 코인) |
| `families/{fid}/places/{id}` | 이름을 붙여 둔 장소 (이름, 좌표, 반경) |
| `families/{fid}/events/{id}` | 캘린더 일정 (이름, 날짜, 시각, 누구, 반복, 메모, 올린 사람) |
| `families/{fid}/pushPrefs/{uid}` | 알림 설정 (종류별 켜기, 조용한 시간, 저녁·아침 알림 시각, 서버가 적는 오늘 보냄 표시) |
| `families/{fid}/pushDevices/{기기id}` | 알림을 받을 기기 (누구, 알림 주소 토큰) |
| `families/{fid}/notes/{id}` | 가족 메모 (내용, 받을 사람, 사라질 날짜, 쓴 사람, 확인한 사람들) |
| `families/{fid}/wishes/{id}` | 자녀의 보상 제안 (이름, 그림, 마지막 가격, 누구 차례, 주고받은 가격, 상태) |

코인 보호: 승인, 장부 기록, 잔액 증가는 한 묶음으로 처리되고 부모만 할 수 있습니다.
같은 수행 기록으로는 두 번 지급되지 않습니다.
자녀가 퀘스트를 만들 수 있는 경우는 두 가지뿐입니다: 부모가 낸 금액을 수락했을 때,
부모가 허용한 버튼을 눌렀을 때. 어느 쪽이든 코인은 부모가 완료를 승인한 뒤에만 지급됩니다.
